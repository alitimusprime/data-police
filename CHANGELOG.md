# Changelog

- Introduced Data Police branding and the Northstar Retail reliability workspace.
- Added SQL, live REST and CSV ingestion, 19 executable assets and immutable Parquet storage.
- Added historical profiling, versioned quality rules, statistical monitors and independent freshness detection.
- Added dataset lineage, incident correlation, evidence ranking, investigation reports and verified recovery.
- Added the connected React product interface and ten actual source/transformation fault scenarios.
- Added local authentication, safe application errors, optional filtered AI evidence submission and local API documentation.
- Added Alembic migrations, PostgreSQL/Redis/Celery/Dagster deployment definitions, GitHub Actions CI and reproducible dependency locks.
- Added backend, real-broker and browser acceptance checks, setup guidance, operational documentation and a release manifest.

Verification boundaries and exact results are recorded in `docs/VERIFICATION.md`.
